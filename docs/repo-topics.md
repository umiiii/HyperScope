# 仓库 Topics

GitHub 的 Topics 是仓库设置，不在代码里，所以这份清单需要手动应用一次：
打开仓库首页 → 右侧 **About** 的齿轮图标 → 把下面的词粘进 **Topics** 输入框 → **Save changes**。

## Topics

```text
hyperliquid hip-3 perpetuals defi crypto position-monitor trading-tools pwa web-push push-notifications service-worker nextjs react typescript postgresql railway
```

逐条说明：

| Topic | 为什么 |
| --- | --- |
| `hyperliquid` | 数据源与监视对象 |
| `hip-3` | 读取全部 HIP-3 builder DEX，而不只是主永续 DEX |
| `perpetuals` | 监视的是永续合约仓位 |
| `defi` / `crypto` | 常用的大类检索词 |
| `position-monitor` | 项目要解决的问题 |
| `trading-tools` | 同类工具的聚合话题 |
| `pwa` | 移动优先、可添加到主屏幕 |
| `web-push` / `push-notifications` | 仓位变化通过 Web Push 通知设备 |
| `service-worker` | 页面关闭后仍能显示系统通知 |
| `nextjs` / `react` / `typescript` | 主要技术栈 |
| `postgresql` | 快照、变化记录与订阅的持久化 |
| `railway` | 仓库自带 Web 与 Worker 两份 Railway 配置 |

## About 区的另外两项

顺手一起填，检索和分享效果比只有 Topics 好：

- **Description**：`移动优先的 Hyperliquid 永续仓位监视 PWA，仓位变化时通过 Web Push 通知设备`
- **Website**：部署后的 Railway 公网域名
